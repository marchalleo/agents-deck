# agents-deck — projet du Leamaginarium

Ce dépôt est un fork de [brushknight/agents-deck](https://github.com/brushknight/agents-deck), adapté pour Léo.

- **Règles de l'agence** : la charte `~/Leamaginarium/CLAUDE.md` (ouvrir les sessions à la racine de l'agence).
- **Règles techniques du projet** : celles de l'auteur, dans `AGENTS.md` (tests à lancer, sécurité, structure). Les respecter.
- **Suivi** : `etat.md` (à lire en début de session), `decisions.md`, `cahier-des-charges.md`, `brainstorm.md`.
- **Fork léger** : ne pas modifier les fichiers de l'auteur sans ticket validé, pour garder les mises à jour simples (« Sync fork »).
